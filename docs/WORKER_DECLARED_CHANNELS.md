# Explicit declared channels and fixed owner sessions

The provider accepts an owner-config field `communication_mode: "text_and_artifacts"` only with `experimental_multi_turn: true`. This allows stock Duo developer/Hub text and exact observed tool-execution receipts through the existing private own-input/own-control path for linked as well as no-link workers. It does not call that peer text the reader's original knowledge, send text or token IDs over activation transport, grant tool/file access, or qualify a physical link. Existing no-link multi-turn behavior is unchanged; linked workers without this explicit opt-in retain strict rejection of developer/Hub text and controller-rewritten tool arguments.

`session_binding: "fixed"` is accepted only for the conjunction of linked memory, multi-turn mode and the explicit text_and_artifacts declaration. The private worker session is then exactly the owner-pinned identity.session, so the provider can match a separately pinned GLM bank or Qwen activation route. The existing one-OMP-session-per-worker map is checked first: a different OMP session cannot attach to that worker, even when it requests the same fixed owner identity. Repeated calls from the already bound OMP session retain the same identity. The default multi-turn route still derives the private session from owner and OMP IDs; ordinary non-multi-turn two-call probes remain unchanged. Other communication/session strings, fixed no-link sessions and opt-ins without multi-turn mode fail configuration validation.

These fields are read exclusively from the complete hash-verified owner configuration before process dispatch; altering a field without the matching owner SHA is rejected. They are not accepted as model tool arguments, prompt instructions or request options. The visible experimental model label includes communication mode and session binding so an explicitly mixed-channel run cannot masquerade as strict linked mode. Existing artifact/executable pins, resource limits, private tool-result handling and frozen backbones are unchanged.
