# Research status

Private experiment notebooks and host-specific operational records are maintained
outside the source repository. Their removal does not change any experiment's verdict.

Drift has an exploratory cross-model cache path and local regression coverage for
transport integrity, allocation lifetime, rank failures and exchange sequencing.
These mechanisms do not establish reliable two-way semantic recall or native
main-agent/subagent qualification.

The reusable mailbox, coordinator and provider parking boundary have composed local
tests. A complete native run, matching deployed source hashes, independent task
evidence and the no-text-channel audit are still required before a release claim.

See [the roadmap](ROADMAP.md), [build status](BUILD_STATUS.md),
[the exchange contract](EXCHANGE_MODULES.md) and [adapter gates](ADAPTERS.md).
