# Bounded linked native echo round

`scripts/omp/linked_round.py` prepares a private source bundle by default; it dispatches only with `--run` and the exact prepared hash, from that copied bundle with its `code` directory on `PYTHONPATH`. The owner profile pins two staged worker entries, independent cleanup readers, installed OMP, endpoint metadata and both frozen translator manifests. An exclusive `run.started` prevents reuse. Preparation does not spawn processes or load models.

Before either actor starts, dispatch verifies and loads only the translator artifacts on the controller CPU, then requires both remote cleanup receipts to be absent. The common 50-second actor deadline begins after this preload and includes OMP startup. Each worker allows two turns, 64 output tokens per turn, 8,192 accounted tokens and 262,144 input bytes; its existing on-host supervisor independently caps lifetime at 60 seconds. Final read-only receipt retrieval may extend report latency beyond that supervisor envelope.

Both fixed native echo actors pause before their sole fixed tool result. The controller keeps one private Unix owner connection per worker, forwarded through existing pinned SSH routes. It taps Qwen's own rows, selects only the final source row, applies reverse-v3 at gain 1 and publishes 12 copies as GLM bank version 2. It selects the first nonempty immutable GLM generated-prefix publication, applies forward-v4 at gain 1.5 and appends at most 128 emitted rows to Qwen. All private copies are bounded and hash checked; source and target labels and exact activation receipts are checked. Empty prefix, timeout or mismatch prevents release and triggers owned cleanup, with no retry.

Only after both receipts does the controller release both tools against the exact ready-file hashes. Success requires each actor's two assistant turns and one fixed tool, independent supervisor cleanup, GLM captures of versions 1 then 2 with both rank receipts per turn, and reaped SSH forwarders. The existing GLM restoration close flag is recorded separately rather than interpreted as an execution failure. Generated output is hashed and discarded; raw activations remain outside agent task roots and are never published.

This is a plumbing qualification only: one selected Qwen row and one GLM generated prefix are exchanged. Newly introduced own prompt/tool-result rows are not exported by the GLM outbox, the final generated tail remains unknown, and first-token causality is not established. It does not qualify full-knowledge sharing, simultaneous Duo project work, source attribution or semantic use of transferred memory.

Synthetic tests use two actual child processes and exercise waiting, ordered exchange, empty-prefix refusal, timeout, source tampering, rank/version checks and independent cleanup after failure. Real dispatch remains a separate owner action using a fresh, frozen private profile; no scientific stage advances from these tests.
