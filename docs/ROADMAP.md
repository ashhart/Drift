# Roadmap

[Current status](STATUS.md) separates completed engineering checks from open
product and scientific gates. This roadmap does not authorize model execution,
training, service restarts or changes to a frozen evaluation.

## Product work

The next product gap is operator-independent native setup for the supported
GLM/Qwen pair, followed by a stock Duo task with declared channels and bounded
cleanup. Preserve the tested persistent coordinator and stage/confirm ordering.
Do not substitute the CLI's local reference mode for a qualified native pair.

Recall, source attribution, final-tail coverage and repeated-run reliability
need separate evidence. More adapters and translators follow their own native
parity and qualification gates rather than a model-name compatibility list.

## Research sequence

The [engineering contracts](reference/CONTRACTS.md) retain M-1 through M6.
Implement the first failing gate; local tests or a bounded lifecycle run do not
advance a scientific stage without its evidence.

| Stage | Required exit evidence |
| --- | --- |
| M-1 | Verified inventory, pinned contracts, budgets, isolation and actual series rules |
| M0a | Stock parity, complete self-prefix import, exact hard-off identity and frozen hashes on intended runtimes |
| M0b | Controlled same-family E1 baseline; faithful paper replication labeled separately |
| M1 | Cross-family one-way E1/E2, independent directional maps, causal/channel audit and declared costs |
| M2 | Prior-epoch scheduling, bounded resources, failure/recovery tests and matched E3 solo/text comparisons |
| M3 | Private mailbox branches, addressing, clean counterfactual replay and held-out correct incorporation |
| M4 | Qualified runtime parity, explicit buffer lifetime/visibility and matched TCP/MCDMA inference replay |
| M5 | Isolated fair E4 project comparison, artifact-channel audit and reproducible evidence package |
| M6 | Frozen policy ABI, reference competitor, hidden-data isolation and enforced training/runtime budgets |

For M6, pin allowed sidecar hooks and prohibit backbone changes, hidden-answer
access or weakened adapter/channel checks; hidden-pair calibration requires a
separate approved split and budget, not training on the evaluation task.

The earlier D0-D7 product/research proposal is preserved in the
[dated roadmap](history/ROADMAP-2026-09-20.md), not used as today's deployment
inventory or as a promise to support additional families in this release.
