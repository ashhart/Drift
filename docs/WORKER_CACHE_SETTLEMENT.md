# Settle native state before a worker thread handoff

The Studio worker previously evaluated only KV-layer keys, values and indexer keys before releasing its native gate. The installed Qwen runtime also retains convolution, recurrent and PLE state in `ArraysCache.state`, raw selector positions and a pooled-selector buffer in `QSAKVCache`. Those lazy arrays could cross from the main prefill thread into the background generation thread without being materialized by their producer.

A guarded public random `Qwen4ExpGatedDeltaNet` fixture reproduced the distinction without loading pretrained weights: main-thread decode passed, main-prefill/background-decode failed with `There is no Stream(gpu, 0) in current thread.`, and placing both prefill and decode on the background thread passed. Merely selecting or creating a stream context did not fix the failure. Evaluating recurrent cache slots before changing threads did fix it.

The small settlement helper now evaluates every array leaf in each cache's public state and direct native attributes, under the existing `NativeGate` lock on the producing thread. It traverses only built-in list, tuple and dictionary containers, deduplicates aliases, and bounds traversal to 256 cache objects, 16 nesting levels and 16,384 visited nodes. It deliberately avoids following model-module references such as a pooled-indexer cache tag. No cache values, positions, model weights, generation decisions or thread scheduling are changed.

The exact helper was tested against the installed `ArraysCache` and `QSAKVCache`, including four recurrent/conv/PLE slots, raw index state and pooled selector state. Main-prefill/background-decode and a return to main-thread decoding passed; the first result matched the same random component's main-thread reference with maximum absolute difference zero. The fixture used a 128 MiB device-memory cap, the unchanged host resource guard and a 20-second process alarm. It was a tiny random component test, not another native model request.

Focused regressions execute the actual Studio settlement callback and verify that non-KV, nested and pooled states are included, already-materialized arrays cross threads under the native lock, model references are excluded, and evaluation failures poison the gate. The real Qwen echo still requires a separately authorized confirmation with the frozen combined fixes; this evidence does not establish tool continuation, source ownership, simultaneous collaboration or GPU allocator release.
